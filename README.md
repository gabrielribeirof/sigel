# SIGEL
## Sistema de Gestão de Estoque e Locação

## Requisitos

- Docker Engine

## Como executar

Execute `docker compose up -d` para iniciar o sistema.

Frontend estará disponível em `http://localhost:5173`, backend em `http://localhost:4000` e banco de dados em `localhost:5432` (acessível por padrão com usuário `myuser` e senha `mypassword`).
